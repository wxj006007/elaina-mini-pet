# 依蕾娜 Mini 宠物形象

以《魔女之旅》依蕾娜为灵感的银发紫眸 Q 版魔女伙伴。

## 下载

[下载原始动画素材](https://raw.githubusercontent.com/wxj006007/elaina-mini-pet/main/elaina-spritesheet.png)

`elaina-spritesheet.png` 是透明背景 PNG 动画精灵图，格式为 v2：1536 × 2288 像素，8 列 × 11 行，每格 192 × 208 像素。

## 在桌面端安装

安装了支持自定义宠物的 ChatGPT / Codex 桌面应用后，复制下面的完整链接到浏览器地址栏，按提示打开应用并安装。安装后在「设置 → Pets」中选择「依蕾娜」。

```text
codex://pets/install?name=%E4%BE%9D%E8%95%BE%E5%A8%9C&imageUrl=https%3A%2F%2Fraw.githubusercontent.com%2Fwxj006007%2Felaina-mini-pet%2Fmain%2Felaina-spritesheet.png&description=%E9%93%B6%E5%8F%91%E7%B4%AB%E7%9C%B8%20Q%20%E7%89%88%E9%AD%94%E5%A5%B3%E4%BC%99%E4%BC%B4&spriteVersionNumber=2
```

此安装链接使用仓库中的公开图片，不需要素材创建者的账号。

如果应用无法识别链接，请先检查版本与 Pets 功能是否可用。手动导入时，需要使用支持 v2 精灵图的入口，并保留原始图片尺寸和透明背景。

[官方安装链接说明](https://learn.chatgpt.com/docs/reference/commands#pets)
